# AnvilBoundless

Плагин для Minecraft серверов на Paper (1.21+) с Java 21, который убирает раздражающие ограничения наковальни и дает больше контроля над процессом объединения предметов.

## Возможности

- **Обход "Слишком дорого!"** - Убирает ограничение в 39 уровней, позволяя объединять любые предметы
- **Контроль максимальной стоимости** - Настраиваемый лимит стоимости ремонта
- **Сохранение сверхуровневых зачарований** - Защищает зачарования выше максимального уровня от понижения при объединении

## Конфигурация

После первого запуска будет создан файл `config.yml`:

```yaml
# AnvilBoundless Configuration

# Обойти ограничение "Слишком дорого!"
bypass-too-expensive: true

# Максимальная стоимость в наковальне (если 0, то неограниченно)
max-repair-cost: 39

# Сохранять сверхмаксимальные уровни зачарований
keep-overleveled-enchants: true
```

### Опции конфигурации

- **`bypass-too-expensive`** (true/false) - полностью отключает ограничение "Слишком дорого!"
- **`max-repair-cost`** (число) - максимальная стоимость, отображаемая в наковальне (0 = без ограничений)
- **`keep-overleveled-enchants`** (true/false) - сохраняет зачарования выше максимального уровня при объединении

## Команды

- **`/anvilboundless reload`** - Перезагружает конфигурацию плагина (нужно право `anvilboundless.reload`)

## Как это работает

### Обход ограничения "Слишком дорого!"
Плагин автоматически устанавливает максимальную стоимость ремонта на максимально возможное значение, когда включена опция `bypass-too-expensive`. Это позволяет объединять предметы, которые обычно были бы недоступны из-за ограничения в 39 уровней.

### Сохранение сверхуровневых зачтарований
Если опция `keep-overleveled-enchants` включена, зачарования выше максимального уровня (полученные через команды или другие плагины), сохраняют эти уровни на новом предмете.
Пример:
- Предмет 1: Зачарование Острота VI (макс. уровень V)
- Предмет 2: Зачарование Прочность IV (макс. уровень III)
- Результат: Зачарование Острота VI и Прочность IV
- Если опция выключена: Зачарование Острота VI и Прочность III

## Совместимость

- **Версия Minecraft:** 1.21+
- **Серверное ПО:** Paper, Purpur
- **Версия Java:** 21+
- **Зависимости:** Нет

## Установка

1. Скачайте последнюю версию `AnvilBoundless.jar` из раздела [Releases](../../releases)
2. Поместите файл в папку `plugins` вашего сервера
3. Перезагрузите или запустите сервер
4. Настройте плагин через `plugins/AnvilBoundless/config.yml` и выполните `/anvilboundless reload` для применения изменений
